# プロジェクト概要

## ゲームについて

Pygameで作られた、見下ろし型の2Dシューティングゲームです。
マップと武器を選び、移動・射撃・リロード・回復を行います。
ルームコードを使ったオンライン対戦とランダムマッチがあり、オンライン対戦ではホストがゲーム状態を更新します。

## ディレクトリ構成

```text
2D_Game/
├─ backend/              ゲーム状態、プレイヤー、武器、通信など
├─ frontend/             メニュー、描画、HUD、視界など
├─ images/               ゲームで使う画像素材
├─ relay_server/         WebSocketサーバー
├─ main.py               アプリケーションの起動処理
├─ constants.py          画面サイズ、色、ゲーム設定値
├─ resources.py          画像などのリソース配置先を解決
├─ requirements.txt      クライアント側Python依存関係
├─ build_exe.bat         PyInstallerでWindows実行ファイルを作成
└─ TopDownShooter.spec   PyInstallerのビルド設定
```

## ファイルごとの役割

### ルートファイルの分類

#### アプリケーション本体

| ファイル | 役割 |
| --- | --- |
| `main.py` | **起動・画面初期化**。Pygameとウィンドウを初期化し、メニューを経由してゲームを開始します。 |

#### 設定・リソース管理

| ファイル | 役割 |
| --- | --- |
| `constants.py` | **ゲーム設定**。画面サイズ、色、プレイヤー性能、視界、HUD配置、リレーサーバーURLなどをまとめます。 |
| `resources.py` | **素材の場所の解決**。通常のPython実行時とPyInstallerで画像フォルダを切り替えます。 |

#### 依存関係・ビルド

| ファイル | 役割 |
| --- | --- |
| `requirements.txt` | クライアントが必要とする `pygame` と `websockets` を指定します。 |
| `build_exe.bat` | 仮想環境を用意し、PyInstallerで `TopDownShooter.exe` をビルドします。 |
| `TopDownShooter.spec` | PyInstallerの入力ファイル、画像データ、実行ファイル設定を記述します。 |
| `.gitignore` | Pythonキャッシュや仮想環境、ビルド生成物をGitの対象外にします。 |

### `backend/`

| ファイル | 役割 |
| --- | --- |
| `game.py` | ゲームループ、入力、ゲーム状態、衝突、ネットワーク同期、描画をします。オンライン対戦ではホストがシミュレーションを進めます。 |
| `player.py` | プレイヤーの位置、移動、照準、射撃、弾薬、リロード、HP、アイテムを管理します。 |
| `weapons.py` | 武器の性能と画像ファイル名を定義します。武器名から武器データを取得します。 |
| `entities.py` | 弾、手榴弾、爆発の状態・更新・描画に使うクラスを定義します。 |
| `maps.py` | マップごとの壁とプレイヤー出現位置を定義します。 |
| `network.py` | TCPソケットを使うメッセージ送受信クラスです。JSONメッセージを扱います。 |
| `relay_connection.py` | WebSocketリレー経由の接続クラスです。ルーム接続とランダムマッチの待機・ペアリングを扱います。 |
| `__init__.py` | `backend` パッケージを示します。 |

### `frontend/`

| ファイル | 役割 |
| --- | --- |
| `menu.py` | モード、マップ、武器の選択と、ルーム作成・参加・ランダムマッチ時の待機画面を扱います。 |
| `hud.py` | 武器表示、HP、リロード表示、所持アイテム欄を描画します。 |
| `vision.py` | 壁へのレイキャストでプレイヤーの視界を計算し、見える位置を判定します。 |
| `weapon_sprites.py` | 武器画像の読み込み・縮小と、照準方向への回転描画を行います。 |
| `render_utils.py` | 透過サーフェスの生成や回転矩形の描画など、描画処理を補助します。 |
| `__init__.py` | `frontend` パッケージを示します。 |

### `relay_server/`

| ファイル | 役割 |
| --- | --- |
| `server.py` | 4桁ルームコードによる接続とランダムマッチの待機列を管理し、ペアになった2人のWebSocket間でゲームメッセージを中継します。 |
| `requirements.txt` | リレーサーバー側の `websockets` 依存関係を指定します。 |

### `images/`

ゲーム内で使用する画像素材です。武器ごとの横向き画像と構えた画像、アイコン、包帯画像などが入っています。武器画像のファイル名は `backend/weapons.py` から参照されます。

## 起動とゲームの流れ

1. `main.py` がPygameを初期化して `frontend/menu.py` のメニューを表示します。
2. メニューでモードを選び、必要に応じてマップと武器を選択します。
3. `backend/game.py` の `Game` が入力、状態更新、衝突判定、描画を進めます。
4. オンライン対戦ではクライアントが操作入力を送り、ホストがゲーム状態を計算してスナップショットを返します。

## メニューのモード

- **ランダムマッチ**: リレーサーバーの待機列で相手を探します。ペア成立後、一方がホスト役となってマップと武器を選びます。
- **ルーム作成**: ホストが4桁のルームコードを発行し、相手の参加を待ちます。
- **ルーム参加**: 相手のルームコードを入力して接続します。
- **ローカルプレイ**: ネットワーク接続を使わない1人プレイです。

ルーム接続とランダムマッチはいずれも `constants.py` の `RELAY_URL` を使います。ランダムマッチを利用するには、クライアントの変更に加えて `relay_server/server.py` を稼働中のリレーサーバーへ反映する必要があります。

## 主な操作

| 操作 | 動作 |
| --- | --- |
| `W` `A` `S` `D` | 移動 |
| マウス | 照準 |
| 左クリック | 射撃 |
| 右クリック | リロード |
| `Space` | 回復アイテムを使用 |
| `R` | ゲーム終了後に再戦・武器再選択 |
| `Esc` | 終了、または選択・待機画面から戻る |

## ダウンロードからプレイまで

### Windows実行ファイルを使う場合

1. 配布元から `TopDownShooter.exe` をダウンロードします。
2. ダウンロードしたファイルを任意のフォルダに置きます。
3. `TopDownShooter.exe` を起動します。
4. メニューでモードを選び、画面の案内に従ってマップや武器を選びます。

この方法ではPythonのインストールは不要です。実行ファイルは `build_exe.bat` で作成でき、出力先は `dist/TopDownShooter.exe` です。

### ソースコードから起動する場合

1. 配布元からプロジェクト一式をZIPでダウンロードし、展開します。`images/` フォルダも必要です。
2. Python 3をインストールします。
3. 展開した `2D_Game` フォルダでターミナルを開き、依存関係をインストールします。

   ```powershell
   py -m pip install -r requirements.txt
   ```

4. 同じフォルダでゲームを起動します。

   ```powershell
   py main.py
   ```

### 起動後の選択

メニューで数字キーを押してモードを選びます。

- `1`: インターネット上のランダムマッチ
- `2`: ルームを作成し、表示された4桁コードを相手に伝える
- `3`: 相手から受け取った4桁コードを入力して参加する
- `4`: ローカルの1人プレイ

オンライン対戦にはインターネット接続と、`constants.py` の `RELAY_URL` で指定されたリレーサーバーが稼働していることが必要です。ランダムマッチを使うには、サーバー側にもマッチメイキング対応版の `relay_server/server.py` が反映されている必要があります。

## 依存関係とビルド

- クライアント依存関係: `requirements.txt`
- リレーサーバー依存関係: `relay_server/requirements.txt`
- Windows実行ファイルのビルド手順: `build_exe.bat`
- ビルド成果物: `dist/TopDownShooter.exe`
